# EggerMath Logo & Icons
All site icons are simplified Saitama (One Punch Man) face — red (#cc0000) square, peach skin (#e8c8a0), black eyes/mouth.

Files:
- `logo.svg` — source (32×32, `favicon.svg` copy)
- `favicon.ico` — 48×48 multi-size
- `icon-192.png` / `icon-512.png` — PWA icons
- `apple-touch-icon.png` — iOS 180×180
- `og-image.svg` — 1200×630 social preview

Source still served from `/favicon.*` etc. (Cloudflare needs root). `public/logo/` is archive for you.
