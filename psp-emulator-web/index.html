Multiplayer (Ad-Hoc Networking)
Configure relay server to play online.
How to play multiplayer:
1. One player hosts a relay server (see below)
2. All players set the same relay server IP
3. Launch the same game and use in-game ad-hoc lobby

To run a relay server on your PC:
npx ppsspp-web-relay or use the ppsspp-web relay binary on port 27312
All processing runs on your device. No files are uploaded to any server.
